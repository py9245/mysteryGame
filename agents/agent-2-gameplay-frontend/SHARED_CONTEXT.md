# Agent 2 Shared Context

## 제품 해석

1. 점수와 정답 성공의 진실 원본은 `개인`이다.
2. 다른 플레이어의 질문 내용, 정답 시도 내용, 오답 여부, 실시간 점수는 스테이지 중 노출하지 않는다.
3. 메인 게임 화면은 `왼쪽 40 / 가운데 40 / 오른쪽 20` 구조다.
4. 오른쪽 20%는 `질문방 / 1:1 채팅 / 본인 점수 / 상태` utility rail이다.
5. 비로그인 사용자는 랜덤 닉네임만 보이고 수정할 수 없다.
6. 공개방 / 비밀방 / 연습모드를 지원한다.
7. 룰북은 메인 / 대기방 / 게임중에서 항상 모달로 열려야 한다.

## UI가 반드시 지켜야 할 것

- `RoomSnapshot`을 source of truth로 본다.
- private chat은 전화형 상태를 분명히 보여준다.
- investigation queue는 대기열, 자동 입장, blocked reason, cooldown을 분명히 보여준다.
- 첫 플레이어를 위한 온보딩 3개 가이드를 제공한다.

## 현재 핵심 미완료

- 메인 / 인증 / 방 찾기 화면 서비스형 마감
- 룰북 / 온보딩 모달 통일
- 40/40/20 레이아웃 정보량 축소
- private chat / queue UI 실연결
- 결과 / 전적 / 모바일 마감
