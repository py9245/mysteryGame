# Hint Policy

힌트는 게임이 멈추지 않도록 만드는 안전장치다.

## 목적

- 후반부 정체를 줄인다.
- 플레이어가 정답 시도를 더 늦추기만 하는 상태를 막는다.
- AI 판정 실패가 생겨도 게임 진행이 멈추지 않게 한다.

## 공개 원칙

- 힌트는 약한 것부터 강한 순서로 공개한다.
- 공개된 힌트는 되돌리지 않는다.
- 첫 정답 성공, 경과 시간, 운영자 강제 공개를 모두 트리거로 허용한다.
- `first_player_solved`는 다음 공개 힌트 1단계만 앞당기는 기본 트리거다.
- `time_elapsed`는 약한 힌트부터 순차 공개하는 기본 트리거다.
- `stage_pressure`는 시간이 부족할 때 한 단계 더 강한 힌트를 허용하는 압박 트리거다.
- `operator_forced`는 운영자가 마지막 공개 범위를 직접 열 때만 사용한다.

## 권장 트리거

- `time_elapsed`
- `first_player_solved`
- `operator_forced`
- `stage_pressure`

## 힌트 레벨

- `weak`
- `medium`
- `strong`
- `final`

## 작성 규칙

- 힌트는 사건 진실을 직접 말하지 않는다.
- 힌트는 필요한 방향을 좁혀주지만 답을 전부 공개하지 않는다.
- 각 힌트는 다음 힌트보다 분명해야 한다.
- `final` 힌트도 답안을 그대로 쓰지 말고, 범인/수단/동기 중 어떤 축이 남았는지까지만 좁힌다.
- 공개 범위는 `publicText`에만 제한하고 `internalNote`는 운영자 전용으로 남긴다.
