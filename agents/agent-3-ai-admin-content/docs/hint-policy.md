# Hint Policy

힌트는 게임이 멈추지 않도록 만드는 안전장치다.

## 목적

- 후반부 정체를 줄인다.
- 플레이어가 정답 시도를 더 늦추기만 하는 상태를 막는다.
- AI 판정 실패가 생겨도 게임 진행이 멈추지 않게 한다.

## 공개 원칙

- 힌트는 약한 것부터 강한 순서로 공개한다.
- 공개된 힌트는 되돌리지 않는다.
- 첫 정답 성공, 경과 시간, 운영자 강제 공개를 모두 트리거로 허용한다.

## 권장 트리거

- `time_elapsed`
- `first_player_solved`
- `operator_forced`
- `stage_pressure`

## 힌트 레벨

- `weak`
- `medium`
- `strong`
- `final`

## 작성 규칙

- 힌트는 사건 진실을 직접 말하지 않는다.
- 힌트는 필요한 방향을 좁혀주지만 답을 전부 공개하지 않는다.
- 각 힌트는 다음 힌트보다 분명해야 한다.
