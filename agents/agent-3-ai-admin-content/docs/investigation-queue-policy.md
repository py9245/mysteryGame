# Investigation Queue Policy

이 문서는 질문방 대기열의 선입선출, 자동 입장, 재진입 제한을 정의한다.

## 핵심 규칙

- 질문방은 FIFO 대기열이다.
- 대기열에 들어간 순서대로 자동 입장된다.
- 퇴장한 뒤에는 5초가 지나야 다시 진입할 수 있다.
- 조사실이 사용 중이면 새 요청은 대기열에 머문다.
- 현재 스테이지에서 조사실 진입이 막힌 경우는 별도 blocked 상태로 보여준다.

## 플레이어 상태

- `waiting`: FIFO 대기 중
- `autoEnter`: 자동 입장
- `queued`: 대기열 진입
- `requeueCooldown`: 퇴장 후 5초 재진입 대기
- `blockedBusy`: 조사실 사용 중
- `blockedStage`: 현재 스테이지 불가
- `ready`: 입장 가능
- `release`: 다음 차례

## Agent 2용 공개 문구

- 대기열: `FIFO 대기 중`
- 자동 입장: `자동 입장`
- 재진입 제한: `퇴장 후 5초 뒤 재진입`
- 입장 가능: `입장 가능`
- 다음 차례: `다음 차례`
- 불가 사유: `입장 불가 사유`

## 운영자 메모

- 대기열 정렬은 생성 시간 기준 선입선출로 유지한다.
- 재진입 쿨다운은 퇴장 시점 기준 5초다.
- blockedBusy와 blockedStage는 플레이어에게 상세 이유를 풀지 말고 상태 라벨만 노출한다.
