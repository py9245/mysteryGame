# Private Chat Policy

이 문서는 전화형 1:1 채팅의 신청, 응답, 종료, 재신청 정책을 정의한다.

## 핵심 규칙

- 신청을 받은 상대는 15초 안에 응답해야 한다.
- 수락되면 채팅이 시작된다.
- 거절되거나 종료되면 신청자는 10초 동안 다시 신청할 수 없다.
- 채팅이 시작된 뒤 30초가 지나야 퇴장할 수 있다.
- 상대가 이미 통화 중이면 `상대방이 누군가와 이야기 중입니다.`를 보여준다.
- 동시에 여러 요청이 들어오면 수신자는 하나를 선택하고, 나머지는 `busy`로 처리한다.

## 플레이어 상태

- `incoming`: 요청이 도착한 상태
- `choose`: 수신자가 선택해야 하는 상태
- `busy`: 상대가 다른 통화 중인 상태
- `accepted`: 수락됨
- `rejected`: 거절됨
- `expired`: 15초 응답 시간이 만료됨
- `inCall`: 통화중
- `minHold`: 30초 전 퇴장 불가
- `cooldown`: 10초 재신청 대기

## Agent 2용 공개 문구

- 신청 도착: `통화 요청이 도착했습니다.`
- 선택 안내: `하나를 선택하세요.`
- 응답 제한: `15초 안에 응답하세요.`
- busy: `상대방이 누군가와 이야기 중입니다.`
- 거절/종료 후: `10초 뒤 다시 요청할 수 있습니다.`
- 통화 중 퇴장 제한: `채팅 시작 후 30초가 지나야 퇴장할 수 있습니다.`

## 운영자 메모

- 동시 요청은 하나의 수신 선택으로 정리하고, 나머지는 모두 busy 이벤트로 남긴다.
- 거절 또는 종료 로그에는 신청자 쿨다운 시작 시점을 함께 저장한다.
- 15초 응답 실패와 30초 퇴장 제한은 상태 문구로 축약하고 내부 계산값은 숨긴다.
