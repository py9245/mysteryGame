# Visibility Matrix

이 문서는 Agent 2가 바로 사용할 수 있는 플레이어/운영자 노출 문구와 공개 범위를 정리한다.

## 원칙

- 플레이어에게는 판단 결과의 `최소 표현`만 준다.
- 운영자에게는 판정 이유와 수정 포인트까지 준다.
- `manual_review`는 플레이어에게 진행 중 상태처럼 보이되, 내부적으로는 운영자 큐에 쌓인다.
- 스테이지 중에는 다른 플레이어의 상세 행동과 점수를 숨긴다.

## 1. 질문 판정 노출 문구

### 플레이어 노출

- `네, 그렇습니다.`
- `아니오, 그렇지 않습니다.`
- `그럴 수도 있습니다.`
- `중요하지 않습니다.`

### 보조 문구

- `질문이 접수되었습니다.`
- `잠시 후 결과가 반영됩니다.`
- `이 질문은 사건 해결에 직접적이지 않습니다.`

### 운영자 노출

- 질문 원문
- `judgement`
- `reasonCode`
- `safetyFlags`
- `manualReviewRequired`
- 관련 `caseId`, `stageNumber`, `playerId`, `teamSlotId`

## 2. 정답 판정 노출 문구

### 플레이어 노출

- 성공: `정답을 맞혔습니다.`
- 실패: `정답이 아닙니다.`
- 검토 중: `운영자 확인이 필요합니다.`

### 관전 전환 문구

- `정답 성공으로 이 스테이지에서는 관전 상태로 전환됩니다.`
- `이제 질문과 정답 입력은 불가능합니다.`
- `남은 정보는 공개 로그로만 확인할 수 있습니다.`

### 운영자 노출

- 제출 원문
- `result`
- `publicOutcome`
- `matchedRequiredKeywords`
- `missingRequiredKeywords`
- `matchedBonusKeywords`
- `reasonCode`
- `needsOperatorOverride`

## 3. 스테이지 결과 공개 범위

### 플레이어 노출

- `스테이지가 종료되었습니다.`
- `당신의 점수 변화`
- `당신의 질문 횟수`
- `당신의 정답 시도 횟수`
- `정답 성공 순서`
- `공개 가능한 사건 요약`

### 플레이어 비노출

- 다른 플레이어의 상세 질문
- 다른 플레이어의 정답 시도 원문
- 다른 플레이어의 비공개 점수 이벤트
- AI 내부 reasoning
- 필수 키워드 전체 목록

### 운영자 노출

- 전체 사건 원문
- 전체 질문 로그
- 전체 정답 로그
- 점수 이벤트 상세
- 공개/비공개 힌트 목록

## 4. 게임 결과 공개 범위

### 플레이어 노출

- 최종 개인 누적 점수
- 개인별 정답 성공 수
- 개인별 추가 키워드 기여
- 공개 가능한 최종 사건 해설

### 플레이어 비노출

- 운영자 보정 전후의 원본 판정
- AI 내부 검토 사유
- 다른 플레이어의 비공개 제출문 전문

### 운영자 노출

- 전체 순위
- 스테이지별 점수 분해
- 수동 보정 로그
- manual review 처리 이력

## 5. 힌트 공개 문구

### 약한 힌트

- `아직 직접적인 단서는 부족합니다.`
- `사건의 방향만 좁혀집니다.`

### 중간 힌트

- `사건의 핵심 관계가 드러납니다.`
- `범행 수단 또는 동기가 더 분명해집니다.`

### 강한 힌트

- `정답 방향이 거의 드러납니다.`
- `남은 것은 세부 연결입니다.`

### 최종 힌트

- `이제는 범인, 수단, 동기를 함께 맞춰야 합니다.`

## 6. admin-only copy

운영자 화면에서만 보여야 하는 문구:

- `manual_review 대기`
- `질문 판정 보류`
- `정답 판정 보류`
- `수동 승인 필요`
- `점수 보정 필요`
- `힌트 강제 공개 가능`

## 7. manual review 공개 경계

Agent 1이 참고해야 하는 경계는 다음과 같다.

- 플레이어에게는 `needs_review` 대신 `운영자 확인이 필요합니다.` 정도만 보여준다.
- 이유 코드와 키워드 매칭 결과는 운영자만 본다.
- 검토가 끝나기 전에는 `correct` 또는 `wrong`처럼 단정된 문구를 임의로 노출하지 않는다.
- 운영자 승인 후에만 최종 문구를 고정한다.

## 8. Agent 2 구현 포인트

- `SpectatorBanner`는 정답 성공 후 읽기 전용 상태를 강하게 보여준다.
- `PrivacyMask`는 타 플레이어 점수와 비공개 행동을 가리는 기본 레이어다.
- `ResultsSummary`는 스테이지 결과와 게임 결과를 분리해서 렌더링한다.
- 질문/정답 결과는 모두 `publicOutcome` 중심으로 렌더링하고, 내부 사유는 숨긴다.
- Agent 2는 `docs/view-model-boundary.md`의 필드별 공개 범위를 최우선으로 따른다.
